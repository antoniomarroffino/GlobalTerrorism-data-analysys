# 🌍 Global Terrorism Data Analysis

## 🧩 Project Overview

This project analyzes terrorist incidents around the world using historical data.  
The goal is to identify global patterns and trends related to terrorism, including the most affected countries, targets, attack types, and temporal evolution of events.

This project was carried out as an academic exercise in data science and exploratory data analysis (EDA).

## 📊 Dataset

Due to GitHub's 100 MB file size limit, the dataset `global_terrorism.csv` is **not included** in this repository.

You can download the full dataset from Kaggle:
🔗 [Global Terrorism Database (GTD) on Kaggle](https://www.kaggle.com/datasets/START-UMD/gtd)

The dataset contains detailed information on terrorist incidents worldwide, such as:

- Date and location of the attack
- Target and attack type
- Weapon used
- Number of casualties (killed/wounded)
- Terrorist group involved
- Country and region

Once downloaded, place the CSV file in the root of this project directory to run the notebook.

## 🔍 Performed Analyses

The main notebook (`global_terrorism.ipynb`) includes:

- 🗓️ **Timeline of terrorist events** over the years
- 🌐 **Heatmaps and maps** of global attack distribution
- 🧨 **Attack types and weapons** most commonly used
- 🏴 **Most active terrorist groups**
- 🏙️ **Most affected countries and cities**
- 🔁 Year-over-year trends in attack frequency and lethality
- 📊 Various visualizations for geographic and categorical breakdowns

## 🛠️ Technologies Used

- **Python 3**
- **Pandas** – data manipulation
- **Matplotlib / Seaborn / Plotly** – visualization
- **Jupyter Notebook** – exploratory analysis

## 🚀 How to Run the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/antoniomarroffino/GlobalTerrorism-data-analysys.git
   cd GlobalTerrorism-data-analysys
   ```

2. Download the dataset from Kaggle and place it here as:
   ```
   global_terrorism.csv
   ```

3. Open the notebook:
   ```bash
   jupyter notebook global_terrorism.ipynb
   ```

4. Install the required libraries:
   ```bash
   pip install pandas matplotlib seaborn plotly
   ```
